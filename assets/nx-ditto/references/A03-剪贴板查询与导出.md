# A03 · 剪贴板查询与导出

全部命令都以 `node bin/ditto.mjs clip` 开头（`clip` 是命令组，`nx-ditto` 是工具名）。

## 命令一览

| 命令 | 作用 | 关键 flag |
| --- | --- | --- |
| `clip info` | 库位置与统计 | — |
| `clip list` | 列出最近条目 | `--limit` `--offset` `--page` `--type` `--since` `--include-grouped` |
| `clip images` | 只列图片条目 | `--limit` `--offset` `--page` `--since` |
| `clip text` | 导出最近文本内容 | `--limit` `--offset` `--page` `--since` |
| `clip show <id>` | 看一条详情 | — |
| `clip image <id>` | 取一条图片，还原成 PNG | `--out` |
| `clip export` | 批量导出图片 | `--limit` `--out` `--format` `--dry-run` |
| `clip now` | 读当前剪贴板 | `--out` |

## 过滤

```bash
# 最近 100 条（不限类型）
node bin/ditto.mjs clip list --limit 100

# 只看图片
node bin/ditto.mjs clip list --type image --limit 20

# 只看最近一天的
node bin/ditto.mjs clip list --since 1d

# 只看 2026-11-01 之后的
node bin/ditto.mjs clip list --since 2026-11-01

# 全部（0 = 不限条数）
node bin/ditto.mjs clip list --limit 0
```

`--since` 支持：`30m` `2h` `3d` `1w` `2026-11-01` `2026-11-01T10:30` Unix 时间戳。

## 翻页

条目多的时候用 `--page` 或 `--offset` 往后翻（往回翻 = 更早的历史）：

```bash
# 第 3 页，每页 20 条
node bin/ditto.mjs clip list --limit 20 --page 3

# 跳过前 30 条，取接下来 10 条
node bin/ditto.mjs clip images --limit 10 --offset 30
```

- `--page` 从 1 开始算；`--offset` 是「跳过前 N 条」
- 两者同时给以 `--offset` 为准
- 每条结果都带 `total`（总条数）和 `pages`（总页数）——翻页器与「还剩几页」都靠它
- 翻到不存在的页返回空列表，但 `total` / `pages` 照报，不报错

## 导出图片

```bash
# ① 先看要写什么（不落盘）
node bin/ditto.mjs clip export --limit 10 --dry-run

# ② 真导出
node bin/ditto.mjs clip export --limit 10 --out D:\shots

# ③ 导出成 BMP（无损但大）
node bin/ditto.mjs clip export --limit 10 --format bmp --out D:\shots
```

规则：

- 默认输出目录是 `~/.nx-ditto/exports`（本机用户目录下的项目数据目录）
- **不覆盖同名文件**：已存在就自动加 `-1` / `-2` 后缀
- 一次只处理一张图（内存里不攒着几十兆的位图），大库导出慢是正常的
- 文件名格式：`clip-<id>-<时间戳>.png`

## 取单条

```bash
# 文本条目：直接打印
node bin/ditto.mjs clip show 34600

# 图片条目：存成 PNG（默认 ~/.nx-ditto/exports）
node bin/ditto.mjs clip image 34595

# 指定目录
node bin/ditto.mjs clip image 34595 --out D:\shots
```

## 当前剪贴板

```bash
node bin/ditto.mjs clip now
```

输出可能是三种之一（也可能同时有几种）：

```
[图片] 1920x1080 -> D:\shots\clip-now-20261103-010203.png
[文件] D:\a.txt, D:\b.png
```

或者直接是文本内容本身。

`clip now` 与 `clip list` 的区别：**now 只给此刻的值**，不需要任何历史；
list 给的是 Ditto 攒下来的记录。

## 接给 agent

```bash
# 结构化数据
node bin/ditto.mjs clip list --limit 5 --json

# 只要文本内容
node bin/ditto.mjs clip text --limit 3 --json
```

`--json` 下错误也是 JSON：`{ "ok": false, "error": "...", "code": "..." }`。
`error` 里带「不存在」表示库或目标找不到，带「用法:」表示参数写错了。

## 注意

- 剪贴板历史里可能有密码、token、验证码——`clip text` / `clip show` 会原样打出来
- 库是 Ditto 自己写的，本工具**只读**；只有 `clip export` / `clip image` /
  `clip now --out` 会写文件，且只写新文件
